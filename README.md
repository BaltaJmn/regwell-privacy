# regwell-privacy

Public web of **Regwell**, a FAR/AIM reader for iPhone and iPad. To be served at
<https://regwell.baltajmn.dev/> by GitHub Pages from `main`, behind Cloudflare (CNAME `regwell` to
`baltajmn.github.io`, proxied), like `humwell-privacy`. Not published yet: no repository, no DNS.

| Path | What it is |
|---|---|
| `index.html` | What the app does, sources and disclaimer, price, support contact. Support and marketing URL in the App Store |
| `privacy/` | Privacy policy. The URL in the app's paywall, Settings and the App Store |
| `legal.html` | Legal notice (LSSI art. 10), same owner details as the other apps' webs |
| `rw/` | Stylesheet and icons |

Terms of use are Apple's standard EULA. The app's code lives in `~/AndroidStudioProjects/Regwell`.
